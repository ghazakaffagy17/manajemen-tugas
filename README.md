# Sistem Manajemen Tugas

Aplikasi manajemen tugas untuk membantu pengguna mengelola aktivitas akademik dan pekerjaan secara terstruktur.

## Fitur

- Authentication pengguna
- Manajemen mata kuliah
- Manajemen tugas
- Status Kanban
- Subtask management
- Dashboard produktivitas
- Search dan filter tugas

## Teknologi

- Node.js
- Express.js
- JavaScript
- JSON Database
- Cypress Testing
